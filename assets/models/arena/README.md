# Arena architecture

These five source files are copied unchanged from the project's existing
`assets/models/kits/dungeon` library, which has a `.gdignore` ancestor.
Only this imported subset is used by the game.

- `pillar_decorated.gltf` and `pillar_decorated.bin`
- `wall_arched.gltf` and `wall_arched.bin`
- `dungeon_texture.png`

Source: KayKit Dungeon Asset Pack 1.1 by Kay Lousberg. CC0.
The original license is retained in `LICENSES/KayKit_Dungeon_Pack_1.1_FREE_License.txt`.
The arena batches repeated geometry with MultiMesh and omits decorative collision.

The stone shader, element SVG icons, crystal pedestals, cloak, shoulder armor,
and staff trim were authored in this project.
